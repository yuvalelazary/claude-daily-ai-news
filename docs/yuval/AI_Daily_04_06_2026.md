## How To — Claude Code

### מערכת הזיכרון של Claude Code

אחד הכלים החזקים ביותר ב-Claude Code הוא מערכת הזיכרון המובנית — תיקיית `~/.claude/memory/` (או `.claude/memory/` בתוך פרויקט). הרעיון פשוט אך עוצמתי: Claude יכול לכתוב ולקרוא קבצים בתיקייה הזו, כך שמידע חשוב שומר על עצמו בין שיחות שונות, בין סשנים, ואפילו בין פרויקטים.

**למה זה שימושי?**

בברירת מחדל, כל שיחה עם Claude מתחילה מאפס — אין זיכרון של מה שנאמר קודם. אבל עם מערכת הזיכרון, Claude יכול לשמור העדפות אישיות (למשל שפת תכנות מועדפת, סגנון קוד), היסטוריה של החלטות בפרויקט, רשימות של מה כבר נוסה ולא עבד, מצב ביניים של משימות ארוכות, ורשימות "done" ו-"todo" שנשמרות לאורך זמן.

**איך להשתמש בזה בפועל?**

ניתן לבקש מ-Claude בצורה פשוטה: "שמור את ההחלטה הזו בזיכרון" או "קרא את הזיכרון שלי לפני שאתה מתחיל". Claude יכתוב קובץ JSON או Markdown לתיקיית הזיכרון. בפעם הבאה שתפתח שיחה חדשה, תוכל לבקש "תקרא את הזיכרון שלי" וה-AI ימשיך מהנקודה שעצרת.

**טיפ מתקדם:** ניתן לבקש מ-Claude לנהל קובץ זיכרון ייעודי לכל פרויקט. למשל, `project-memory.json` שיכיל את ארכיטקטורת הפרויקט, ה-API endpoints החשובים, ו-gotchas שגיליתם. בכל שיחה חדשה Claude יקרא קודם את הקובץ הזה ויהיה "up to speed" ברגע.

**הבדל בין זיכרון גלובלי ל-project-level:** הזיכרון ב-`~/.claude/memory/` משותף לכל הפרויקטים, ואילו `.claude/memory/` בתוך ריפוזיטורי שמור רק לאותו פרויקט. זה מאפשר גמישות — מידע אישי כללי גלובלי, ומידע טכני ספציפי נשמר עם הפרויקט.

## סקיל שכדאי להכיר

### /init

הפקודה `/init` היא אחת הנוחות ביותר כשמתחילים לעבוד עם פרויקט קיים ב-Claude Code. הפקודה סורקת אוטומטית את כל מבנה הפרויקט — קבצי קוד, תלויות (package.json, requirements.txt וכד'), תיקיות, קבצי קונפיגורציה — ויוצרת קובץ `CLAUDE.md` מלא ומפורט.

מה זה אומר בפועל? פעם אחת מריצים `/init`, ומקבלים מסמך שמסביר ל-Claude (ולמפתחים חדשים!) איך הפרויקט בנוי, אילו פקודות חשובות קיימות, מה הארכיטקטורה הכללית, ואיפה נמצא כל דבר. בכל שיחה עתידית עם Claude על אותו פרויקט, ה-AI קורא את ה-`CLAUDE.md` ומיד מבין את ההקשר — חוסך הסברים חוזרים ונותן תשובות יותר מדויקות.

זה שימושי במיוחד כשמצטרף מפתח חדש לצוות, כשחוזרים לפרויקט אחרי הפסקה, או כשרוצים שכל מי שמשתמש ב-Claude Code על הפרויקט יקבל אותו הבסיס לשיחה.
