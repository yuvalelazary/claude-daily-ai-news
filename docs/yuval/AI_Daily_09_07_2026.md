## How To — Claude Code

### ניהול הרשאות: תפסיקו לאשר כל פקודה ידנית

אחד הדברים שהכי מעצבנים אנשים חדשים ב-Claude Code הוא ה-"permission prompts" — Claude מבקש אישור לפני כל פעולה: לפני שהוא מריץ `npm test`, לפני שהוא קורא קובץ, לפני שהוא מריץ `git status`. כשעובדים על פרויקט ומאשרים אותן פקודות שוב ושוב, זה מתיש ומאט את העבודה. הפתרון: **ניהול הרשאות מוקדם**.

Claude Code מאפשר לכם להגדיר מראש אילו פקודות ופעולות אושרו אוטומטית, מבלי שתתבקשו בכל פעם. ישנם שני רמות הגדרה:

**הגדרות גלובליות** (חלות על כל הפרויקטים) נשמרות בקובץ `~/.claude/settings.json`. **הגדרות פרויקט** (חלות רק על ספרייה ספציפית) נשמרות ב-`.claude/settings.json` בתיקיית הפרויקט.

בתוך הקובץ תמצאו מקטע `permissions` עם רשימת `allow` ו-`deny`. לדוגמה:

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git status)",
      "Bash(git diff *)",
      "Bash(pytest *)",
      "Read(**)"
    ],
    "deny": [
      "Bash(rm -rf *)"
    ]
  }
}
```

ניתן גם להשתמש בסקיל המובנה `/fewer-permission-prompts` — Claude יסרוק את היסטוריית השיחות שלכם, יזהה אילו פקודות אישרתם שוב ושוב, ויוסיף אותן אוטומטית לרשימת ה-`allow` בפרויקט. זה חוסך הרבה עבודה ידנית.

חשוב להבין את ההיררכיה: הגדרות פרויקט גוברות על הגדרות גלובליות, וכן — הגדרות `deny` תמיד גוברות על `allow`. כלומר, אם אישרתם `Bash(*)` גלובלית אבל הוספתם `deny` ל-`rm -rf *` בפרויקט — Claude לא יריץ פקודות מחיקה הרסניות גם אם תבקשו.

טיפ מתקדם: ניתן להשתמש בסקיל `/update-config` כדי לנהל את ה-`settings.json` בצורה מונחית — ללא צורך לערוך JSON ידנית.

## סקיל שכדאי להכיר

### /verify — בדיקה חיה שהשינוי אכן עובד

`/verify` הוא סקיל שמריץ את האפליקציה בפועל ובודק שהשינוי שביצעתם עובד כמצופה — לא רק שהקוד עובר קומפילציה, אלא שהפיצ'ר עצמו מתנהג נכון. Claude Code מפעיל את הפרויקט, מנווט לתוך הממשק הרלוונטי, מבצע את הפעולה שאמורה לעבוד, ומדווח מה הוא ראה.

הסקיל שימושי במיוחד לפני כל commit משמעותי: יש הבדל גדול בין "הטסטים עוברים" לבין "הפיצ'ר עובד". `/verify` מגשר על הפער הזה. הוא מזהה בעצמו איך להפעיל את הפרויקט (לפי סוג הפרויקט — שרת, CLI, אפליקציית דפדפן) ועובד גם בסביבות מרוחקות כמו Claude Code on the Web. השתמשו בו תמיד לפני שתדחפו שינויים לענף ראשי.
