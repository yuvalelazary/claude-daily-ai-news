## How To — Claude Code

### Hooks — פקודות אוטומטיות שרצות עם כל פעולה של Claude

Hooks הם אחד מהכלים החזקים ביותר ב-Claude Code שרוב המשתמשים לא מכירים. בפשטות, Hook הוא פקודת shell שמוגדרת מראש ורצה אוטומטית בנקודות מפתח במחזור חיי הסשן: לפני שימוש בכלי, אחרי שימוש בכלי, כאשר Claude שולח התראה, או כאשר הסשן מסתיים.

**למה זה שימושי?**

דמיינו שאתם רוצים שכל פעם ש-Claude כותב קוד Python, יופעל אוטומטית `black` לפורמוט. או שכל פעם ש-Claude מריץ `npm install`, תקבלו הודעה ב-Slack. Hooks מאפשרים לבנות אוטומציות כאלה ישירות בתוך סביבת העבודה מבלי להתעסק בקוד חיצוני.

**סוגי Hooks:**

- **PreToolUse** — רץ לפני שימוש בכלי (לדוגמה, לוג לפני שקובץ נכתב)
- **PostToolUse** — רץ אחרי שימוש בכלי (לדוגמה, לינטר אחרי כתיבת קוד)
- **Notification** — רץ כאשר Claude שולח התראה
- **Stop** — רץ כאשר Claude מסיים את תגובתו

**הגדרת Hook — דוגמה מעשית:**

ניתן להגדיר Hooks בקובץ `~/.claude/settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "eslint --fix $CLAUDE_FILE_PATHS"
          }
        ]
      }
    ]
  }
}
```

בדוגמה זו, בכל פעם ש-Claude כותב קובץ JavaScript, ESLint ירוץ אוטומטית ויתקן בעיות עיצוב. זה חוסך זמן רב ומבטיח עקביות בקוד לאורך כל הפרויקט.

**שימושים נוספים:**

- הרצת בדיקות אוטומטית אחרי כל שינוי בקוד
- יצירת לוג מפורט של כל הקבצים שנערכו בסשן
- ביצוע `git commit` אוטומטי בנקודות מסוימות
- שליחת התראה ל-Slack כאשר Claude מסיים משימה ארוכה

Hooks הופכים את Claude Code ממנהל קוד AI לזרימת עבודה אוטומטית ומשתלבת בצוות. הם מגדירים חוקים ש-Claude עוקב אחריהם באופן עקבי — בלי לזכור ובלי לשכוח.

## סקיל שכדאי להכיר

### /init — יצירת CLAUDE.md אוטומטית מהפרויקט הקיים

כשאתם מתחילים לעבוד עם Claude Code על פרויקט קיים, האתגר הראשון הוא "ללמד" את Claude על המבנה, הכינויים, וכללי הקוד הספציפיים לפרויקט. הסקיל `/init` עושה את זה אוטומטית.

כשמריצים `/init`, Claude סורק את הפרויקט כולו — קבצי הגדרות, מבנה תיקיות, dependencies, ו-README — ויוצר קובץ `CLAUDE.md` מקיף. הקובץ מכיל את פקודות הבנייה והבדיקות, מוסכמות הקוד שבשימוש, מבנה הפרויקט, ואזהרות על מקומות רגישים בקוד.

התוצאה המעשית: בכל סשן עתידי, Claude מגיע "מוכן" לפרויקט שלכם ללא צורך להסביר הקשרים מחדש. זה חוסך עשרות הודעות של הסברים בכל פעם ומאפשר להתחיל לעבוד ישירות על המשימה. מומלץ להריץ אותו פעם אחת בתחילת כל פרויקט חדש שמכניסים לסביבת Claude Code.
