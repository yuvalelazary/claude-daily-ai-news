## How To — Claude Code

### מערכת הזיכרון של Claude Code

אחת התכונות החזקות ביותר של Claude Code, שרבים לא מכירים, היא **מערכת הזיכרון** — תיקיית `~/.claude/memory/` שמאפשרת לשמור מידע שיישמר בין סשנים שונים.

**מה זה אומר בפועל?**

כברירת מחדל, Claude Code "שוכח" הכל בסוף כל שיחה. אבל אם שומרים מידע בקובצי JSON בתיקיית הזיכרון, Claude יכול לקרוא אותם בתחילת הסשן הבא וממש "לזכור" פרטים חשובים.

**מה ניתן לשמור בזיכרון?**

- **העדפות אישיות**: האם אתה מעדיף פונקציות קצרות או ארוכות? TypeScript strict mode? הערות בעברית?
- **הקשר פרויקט**: מי הלקוחות המרכזיים, מהי ארכיטקטורת המערכת, מה הכללים שלא לשנות.
- **מעקב אחר משימות**: מה כבר בוצע, מה נמצא ב-backlog, מה דורש תשומת לב.
- **טיפים לסביבה**: פורמט הלוגים, פקודות deployment מיוחדות, כתובות API פנימיות.

**איך זה עובד?**

1. צור קובץ JSON בתיקיית `~/.claude/memory/` (למשל `project.json`)
2. רשום בו מידע רלוונטי בפורמט מובנה
3. בתחילת כל סשן, בקש מ-Claude לקרוא את הקובץ: `"Read memory from ~/.claude/memory/project.json"`
4. Claude ישתמש במידע זה כהקשר לאורך כל השיחה

**דוגמה מעשית:**

```json
{
  "project": "E-commerce Platform",
  "stack": ["Next.js", "PostgreSQL", "Stripe"],
  "conventions": {
    "naming": "camelCase for variables, PascalCase for components",
    "testing": "Always write unit tests with Jest"
  },
  "avoid": ["Never use any", "No console.log in production"],
  "current_sprint": "Implementing checkout flow"
}
```

**טיפ מתקדם**: ניתן להגדיר hook אוטומטי שיטען את הזיכרון בתחילת כל סשן. כך לא צריך לזכור לבקש ממנו — זה קורה אוטומטית. ניתן גם לייצר כמה קבצי זיכרון לפרויקטים שונים ולטעון כל פעם את הרלוונטי.

מערכת הזיכרון הופכת את Claude Code מכלי שמתחיל מאפס בכל פעם — לעוזר שמכיר את הפרויקט שלך לעומק, פעם אחר פעם.

## סקיל שכדאי להכיר

### /run

הסקיל `/run` מאפשר ל-Claude Code להפעיל את הפרויקט שלך, לצפות בהתנהגות האמיתית שלו, ולאמת שינויים בפועל — לא רק בקוד.

**מתי להשתמש בו?**

כאשר ביצעת שינוי בממשק משתמש, הוספת תכונה חדשה, או תיקנת באג — ויש צורך לראות שהכל עובד כמצופה על מסך אמיתי. בדיקות TypeScript ו-Jest מאמתות שהקוד נכון; `/run` מאמת שהתכונה *עובדת*.

**מה הסקיל עושה?**

Claude Code מזהה את סוג הפרויקט (Next.js, Python Flask, React, CLI, אלקטרון וכו'), מפעיל אותו עם הפקודה המתאימה, ואז בודק את הפלט — מחפש שגיאות, מאמת שהתכונה הספציפית מופיעה כראוי ומדווח על כל אי-התאמה שמגלה.

**איך מפעילים?**

פשוט כתוב `/run` בצ'אט, ואפשר להוסיף הוראה ספציפית: `"/run ובדוק שטופס ההתחברות מציג הודעת שגיאה על סיסמה שגויה"`. Claude ידאג להפעיל, לנווט לתכונה, ולדווח חזרה.
