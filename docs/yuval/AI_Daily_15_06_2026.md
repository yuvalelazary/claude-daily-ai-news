## How To — Claude Code

### שרתי MCP: חיבור כלים חיצוניים ל-Claude Code

**MCP — Model Context Protocol** הוא פרוטוקול שפיתחה Anthropic כדי לאפשר ל-Claude Code להתחבר לכלים ושירותים חיצוניים בצורה סטנדרטית ואחידה. בזכות MCP, Claude לא מוגבל יותר לפעולות על קוד מקומי בלבד — הוא יכול לתקשר עם GitHub, Slack, Jira, Notion, מסדי נתונים ועוד, ישירות מתוך השיחה.

**איך זה עובד?** שרת MCP הוא תהליך קטן שרץ ברקע ומחשף כלים לשימוש Claude. לדוגמה, שרת MCP של GitHub מאפשר ל-Claude לקרוא בעיות, ליצור pull requests, לבדוק CI/CD — בלי לצאת מהשיחה. שרת MCP של Slack מאפשר שליחת הודעות, קריאת ערוצים ועדכון צוות בזמן אמת.

**הגדרה:** מוסיפים שרתי MCP בקובץ `~/.claude/settings.json` תחת המפתח `mcpServers`. כל שרת מוגדר עם שם, פקודת הפעלה, וארגומנטים:

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "ghp_..." }
    },
    "slack": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-slack"],
      "env": { "SLACK_BOT_TOKEN": "xoxb-..." }
    }
  }
}
```

**יתרונות מרכזיים:**
- **אינטגרציה חלקה** — Claude רואה את כלי ה-MCP כפי שהוא רואה כלים מובנים, ומשתמש בהם אוטומטית כשצריך
- **אין יציאה מהשיחה** — כל הפעולות החיצוניות קורות ישירות מהקשר השיחה
- **ניתן לבנות בעצמך** — פרוטוקול MCP פתוח, וניתן לכתוב שרתים מותאמים אישית לכל API פנימי בארגון
- **שליטה בהרשאות** — ניתן להגדיר אילו שרתים פעילים ואילו כלים מותרים

MCP הוא אחד הכלים החזקים ביותר ב-Claude Code, והוא ממשיך להתפתח עם יותר ויותר אינטגרציות זמינות מהקהילה.

## סקיל שכדאי להכיר

### /security-review

`/security-review` הוא סקיל מובנה ב-Claude Code שמבצע ביקורת אבטחה מקיפה על כל השינויים שביצעת ב-branch הנוכחי, עוד לפני ש-pull request נפתח.

הסקיל סורק את הקוד שלך לאיתור בעיות נפוצות כמו: הזרקת SQL (SQL Injection), XSS (Cross-Site Scripting), חשיפת מפתחות API ו-secrets, בעיות אבטחה בניהול sessions, שימוש לא בטוח בחבילות npm, ועוד. הוא בוחן את הקוד ברמה עמוקה ומדווח על ממצאים עם הסבר לכל בעיה ומה הסיכון הפוטנציאלי.

**מתי להשתמש?** לפני כל push לענף ראשי, לפני פתיחת PR לקוד production, ולאחר הוספת תלויות חדשות. הסקיל חוסך זמן על ביקורות אבטחה ידניות ומפחית את הסיכון לשינויים עם פרצות שיגיעו לפרודקשן.

פשוט הקלד `/security-review` בכל שלב, וקבל דוח מפורט בשפה טבעית עם המלצות ספציפיות לתיקון.
