## How To — Claude Code

### Agents — שליחת תת-משימות לסוכן נפרד

**מה הבעיה שזה פותר?**

כאשר עובדים עם Claude Code על פרויקטים גדולים, חלון ההקשר (context window) מתמלא מהר מאוד. ברגע שמחצית מהחלון מלאה בתוצאות חיפוש, קבצים שנקראו וביצועי פקודות — Claude מאבד חלק מהיכולת לתת תשובות מדויקות. הפתרון הוא להפעיל **סוכן נפרד (Agent)** שמטפל במשימה ממוקדת, ומחזיר רק את התוצאה החשובה לשיחה הראשית.

**איך זה עובד בפועל?**

כאשר Claude Code מפעיל Agent, הוא יוצר "שיחת בת" מבודדת עם הקשר ריק לחלוטין. הסוכן מקבל רק את ההנחיות שנתת לו, מבצע את המשימה (כולל קריאת קבצים, חיפושים, הרצת פקודות), ואז מחזיר סיכום קצר לשיחה הראשית. כך חלון ההקשר הראשי נשמר נקי, ויכולת ה-AI להגיב בצורה מדויקת נשמרת לאורך כל הפרויקט.

**מתי כדאי להשתמש ב-Agents?**

- **חיפוש בקוד**: "מצא את כל המקומות בקוד שמשתמשים בפונקציה X" — במקום להעמיס את ההקשר בתוצאות grep ארוכות.
- **בדיקת קבצים מרובים**: כאשר צריך לקרוא ולנתח עשרות קבצים, שלח סוכן שיסכם רק את הנקודות הרלוונטיות.
- **משימות מקבילות**: ניתן להפעיל מספר סוכנים בו-זמנית לחסוך זמן — לדוגמה, אחד בודק את הצד השרתי ואחד את הצד הלקוחי.
- **מחקר ברשת**: סוכן ש-fetch-מ מספר מקורות ומחזיר סיכום, במקום לייבא כל התוכן לחלון הראשי.

**דוגמה מעשית:**

```
אתה: "בדוק את כל קבצי ה-TypeScript בתיקיית src/ 
       ומצא שימושים לא עקביים בטיפול בשגיאות. 
       החזר רק רשימה קצרה של ממצאים."
```

Claude יפעיל Agent שיקרא את הקבצים, ינתח, ויחזיר רשימה תמציתית — במקום למלא את ההקשר בתוכן של כל הקבצים.

**מה מרוויחים?**

שיחות ארוכות יותר לפני הצורך ב-/compact, דיוק גבוה יותר לאורך הפרויקט, ויכולת לבצע משימות מורכבות שאחרת היו דורשות פיצול ידני לכמה שיחות. Agents הם כלי עוצמתי במיוחד לפרויקטים עם קודבייסים גדולים.

## סקיל שכדאי להכיר

### /security-review

הסקיל `/security-review` מבצע ביקורת אבטחה מקיפה על כל השינויים שבוצעו בענף (branch) הנוכחי לפני שדוחפים אותם לפרודקשן. במקום לסקור ידנית כל שורת קוד, Claude Code סורק את כל הדיף ומחפש פרצות אבטחה נפוצות כגון: SQL injection, XSS, CSRF, חשיפת מפתחות API, ניהול שגיאות לא תקין, שימוש לא מאובטח ב-dependencies, ועוד.

**מתי להשתמש בזה?**

לפני כל פתיחת Pull Request שנוגעת בלוגיקת אימות, עיבוד נתוני משתמשים, API endpoints, או כל קוד שמתממשק עם בסיס נתונים. גם שינויים שנראים תמימים עלולים להכניס בעיות אבטחה עקיפות.

**איך מפעילים?**

פשוט כתבו בשיחה עם Claude Code:
```
/security-review
```

Claude יסרוק את כל השינויים מאז ה-main branch, יציג ממצאים לפי רמת חומרה (קריטי / גבוה / בינוני / נמוך), ויציע תיקונים קונקרטיים לכל בעיה שנמצאה.
