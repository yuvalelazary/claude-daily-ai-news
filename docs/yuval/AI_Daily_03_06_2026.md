## How To — Claude Code

### קריאות מקבילות לכלים (Parallel Tool Calls)

אחת מהיכולות החזקות ביותר של Claude Code היא היכולת לקרוא למספר כלים בו-זמנית — במקום לחכות שכל פעולה תסתיים לפני שמתחילים את הבאה. זה נקרא **קריאות מקבילות לכלים**, ובאנגלית: Parallel Tool Calls.

**מה הבעיה שזה פותר?**
בעבודה רגילה, Claude מבצע פעולות אחת אחרי השנייה: קורא קובץ, מחכה לתוצאה, קורא קובץ שני, מחכה שוב, וכך הלאה. כאשר יש כמה פעולות שאינן תלויות זו בזו, הגישה הזו מבזבזת זמן יקר. קריאות מקבילות מאפשרות ל-Claude להפעיל מספר כלים בו-זמנית ולאסוף את כל התוצאות יחד.

**איך זה עובד בפועל?**
Claude Code מזהה אוטומטית מתי קריאות לכלים אינן תלויות זו בזו ושולח אותן בו-זמנית. לדוגמה, אם ביקשת מ-Claude לקרוא שלושה קבצים שונים — הוא יקרא את כולם במקביל ולא ברצף.

**דוגמה פשוטה:**
במקום:
```
1. קרא קובץ A → המתן → 2. קרא קובץ B → המתן → 3. הרץ git status → המתן
```
Claude יבצע:
```
1+2+3 בו-זמנית → המתן לכל התוצאות יחד → המשך
```

**מתי זה מועיל במיוחד?**
- כשצריך לקרוא מספר קבצים לפני עריכה
- כשמריצים בדיקות וחיפוש בו-זמנית
- כשמושכים מידע ממספר מקורות (API, מסד נתונים, קבצים)
- כשמבצעים חיפוש ב-grep ובמקביל מריצים git log

**מה מרוויחים?**
חסכון משמעותי בזמן — לעיתים קריאות שהיו לוקחות 30 שניות ברצף מסתיימות תוך 10 שניות. בנוסף, Claude "חושב" בצורה יותר אפקטיבית כי יש לו את כל המידע הנדרש בבת אחת לפני שהוא מחליט מה לעשות.

כדי לנצל את היכולת הזו בצורה מיטבית, ניסחו בקשות שמאפשרות ל-Claude לזהות פעולות עצמאיות. לדוגמה: "קרא את הקבצים A, B ו-C ואמור לי על ההבדלים ביניהם" — ולא שלוש בקשות נפרדות.

## סקיל שכדאי להכיר

### /run

הסקיל `/run` מורה ל-Claude Code להפעיל את הפרויקט בפועל ולצפות בהתנהגות האמיתית שלו — לא רק לקרוא קוד ולנחש מה יקרה.

**מה זה עושה?**
כשמפעילים `/run`, Claude מזהה את סוג הפרויקט (שרת Node.js, אפליקציה Python, CLI, Electron וכדומה), מפעיל אותו בסביבה אמיתית, ומתצפת על הפלט — שגיאות, לוגים, והתנהגות בזמן אמת.

**מתי כדאי להשתמש?**
- לאחר שינוי קוד, כדי לוודא שהתוסף אכן עובד לפני שדוחפים לגיט
- כשרוצים לראות את הפרויקט "רץ" ולא רק לקרוא את הקוד שלו
- כשיש באג שקשה לשחזר — `/run` מאפשר ל-Claude לראות את ההתנהגות בפועל
- לפני פתיחת PR, כדי לוודא שהאפליקציה מתנהגת כמצופה

**איך משתמשים?**
פשוט הקלידו `/run` בצ'אט עם Claude Code, ו-Claude ינסה להפעיל את הפרויקט לפי הדפוסים שהוא מזהה.

**מה מקבלים?**
Claude Code מריץ את האפליקציה, צופה בפלט, ומדווח על מה שראה — כולל שגיאות, אזהרות, ותנהגויות בלתי צפויות. זה הרבה יותר אמין מאשר לנחש מהקוד בלבד.
